## Launch Structure

- Use one ad set with broad business-owner targeting so the creative angle is the main variable.
- Run all three creatives with equal initial budgets.
- Optimize for completed audit submissions, not landing-page views.
- Keep the image, primary text, and headline paired as written during the first test.
- Evaluate cost per completed audit and audit completion rate before judging downstream booked calls.
