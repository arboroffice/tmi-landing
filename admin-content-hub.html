Non-Negotiables
Never finish the If I Owned a list - always end abruptly, tease the next one
Start mid-thought - never "hello", "hey", or "what is up"
End abruptly - no CTA, no sign-off, no "follow for more"
Never say "leverage AI" - say "when the system is built to capture this"
No em dashes - use regular dashes or restructure the sentence
Never say "Not theory. Not hype." - banned phrase
Never teach the mechanism - show the result
Never soften a take - state it clean and move on
Written for operators and field managers - not tech people
Real numbers and specific scenarios - not abstractions
